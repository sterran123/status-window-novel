# 챕터 파일 형식 (story/chapters/CHNN.md)

원고(prose)와 웹 채팅 뷰어(bubble)를 한 파일에서 생성하는 경량 마크업.

```
# CH03. 첫 벽                          ← 첫 줄은 반드시 장 헤더

빈 줄로 나뉜 문단 = 나레이션. 한 줄 한 문장의 웹소설체.

"따옴표 대사는 그대로."

> 태윤: 형, 이거 로그인이 안 돼요.      ← `이름:` 접두 줄 = 그 사람의 말풍선
> 지혁: 어디서부터 막혔어?

[SYS]                                   ← 시스템 메시지 블록
[일일 퀘스트: 막힌 자리 채우기]
보고서 병합: 미완료 (0/1)
[/SYS]

[STATUS]                                ← 상태창 블록
이름: 권지혁
레벨: 3
[스탯]
설명력: 12 관찰력: 15 버팀: 18
[/STATUS]

《아리아: 로그를 읽는 중입니다.》          ← 《》= 아리아 잡담

-사용자1: 방장님 이거 어떻게 써요?       ← `-` 접두 = 채팅/통화 표기

::: scene                              ← 장면 전환 (* * *)

::: choice id="ch04end"
화면 속 커서가 깜빡인다.                ← 프롬프트
- 다시 배포를 누른다 | goto="CH05" | main
- 잠시 눈을 감는다 | goto="BR_rest01"
:::
```

## 규칙

- 선택지는 기본적으로 장 말미 1개. `main` 표시된 것이 원고 루트.
- goto 는 다른 챕터 파일 ID(CH05) 또는 분기 파일 ID(BR_*, END_*).
- `main`이 아닌 분기는 짧은 사이드 씬 파일(story/branches/BR_*.md) 또는 엔딩 파일.
- 나레이션 문단은 원고에 그대로 실림. `> 이름:` 줄은 원고에서 `이름: "내용"`으로 변환.
- 장 내부 분량: 2,800~3,400자(공백 제외) 목표. 12장 전체 3.3만~4만 자.
- 문체: 3인칭(지혁 중심) 나레이션 + 짧은 단문. 시스템 문법은 월드시트 5범주대로.
